# Telegram Web Proxy Wizard

[English](README.md) · ساخته‌شده توسط **sinascorpion**

نصب آسان پروکسی وب تلگرام با SSL خودکار، چند دامنه و سکرت، پشتیبانی CDN،
تگ اختیاری اسپانسر و منوی مدیریت.
هر دامنه سایت سبک خودش را با نام، رنگ و مطالب متفاوت و ثابت نمایش می‌دهد.

## نصب

از سرور اختصاصی اوبونتو استفاده کن؛ نسخهٔ پیشنهادی **24.04** است.
دامنه را به سرور وصل کن و پورت‌های **۸۰ و ۴۴۳** را باز بگذار.
تلگرام باید از `tg://webproxy` پشتیبانی کند.

```bash
curl -fsSLo /tmp/telegram-web-proxy-install.sh https://raw.githubusercontent.com/sinascorpion/telegram-web-proxy/main/install.sh && sudo bash /tmp/telegram-web-proxy-install.sh
```

گزینهٔ **۱ — نصب یا نصب مجدد** را انتخاب کن. دامنه‌ها، سکرت‌ها و تگ‌های
اختیاری را وارد کن و برای هر دامنه CDN و پورت HTTPS مبدأ را انتخاب کن.
Enter در قسمت سکرت، مقدار قبلی را حفظ یا در نصب جدید سکرت تولید می‌کند.
سکرت قبلی با ۳۲ کاراکتر هگز یا پیشوند `dd` پذیرفته می‌شود.

## چند سکرت و چند دامنه

چند دامنه و سکرت با CDNها و تگ‌های متفاوت، هم‌زمان روی همان سرور و IP
کار می‌کنند. چند سکرت برای یک دامنه هم قابل تنظیم است.

در ویزارد می‌توانی دامنهٔ بعدی را اضافه کنی. سکرت‌ها و تگ‌ها را به همان
ترتیب وارد کن: دامنهٔ اول با سکرت و تگ اول، دامنهٔ دوم با سکرت و تگ دوم.
می‌توانی یک سکرت یا تگ را برای همه استفاده کنی، یا ابتدا فقط یک پروفایل
بسازی و بقیه را بعداً اضافه کنی.

از گزینهٔ **۱۰ — مدیریت پروفایل‌ها**، پروفایل اضافه، ویرایش یا حذف کن
و لینک‌های اتصال را ببین. برای چند سکرت روی یک دامنه، پروفایل دیگری با
همان دامنه و سکرت متفاوت بساز.

## مدیریت

```bash
sudo sinascorpion-webproxy
```

نصب مجدد، تنظیمات، تغییر دامنه و سکرت، فعال/غیرفعال‌سازی، وضعیت، لینک‌ها،
مدیریت پروفایل‌ها و حذف از همین منو در دسترس‌اند.
برای به‌روزرسانی نصب قبلی، دستور نصب را دوباره اجرا و گزینهٔ **۱** را انتخاب کن.
در **۹ — Uninstall**، حذف کل پروکسی یا حذف یک دامنه از فهرست را انتخاب کن.
حذف دامنه، سکرت‌ها و تگ‌های مربوط به آن را هم حذف می‌کند؛ دامنه‌های دیگر باقی
می‌مانند و SSL برای استفادهٔ دوباره حفظ می‌شود.

SSL معتبر همان دامنه روی همان سرور دوباره استفاده می‌شود؛ تغییر سکرت به SSL جدید
نیاز ندارد. هنگام حذف، گواهی به‌صورت پیش‌فرض حفظ می‌شود؛ برای پاک‌سازی کامل،
حذف گواهی را هم انتخاب کن. برای حفظ لینک کاربران، دامنه و سکرت قبلی را نگه دار.
نصب دوباره، NGINX پیش‌فرض باقی‌مانده را تشخیص می‌دهد و برای دریافت SSL آن را قطع نمی‌کند.

## CDN و تگ اسپانسر

حالت `none`، `cloudflare` یا `other` را انتخاب کن. رنج و هدر IP معتبر برای
CDNهای دیگر اختیاری است. TLS معتبر مبدأ، WebSocket و درخواست‌های طولانی را
فعال و کش ترافیک پروکسی را غیرفعال کن.

اتصال کاربران روی **۴۴۳** است. پورت مبدأ مثل **۲۰۵۳، ۲۰۸۳ یا ۲۰۹۶** نیاز
دارد CDN اتصال عمومی ۴۴۳ را به آن پورت بفرستد. تنظیم DNS و حساب CDN با خودت است.

تگ اختیاری اسپانسر را از [@MTProxybot](https://t.me/MTProxybot) بگیر؛ تگ باید
۳۲ کاراکتر هگز باشد و نام کانال کافی نیست. نمایش اسپانسر به ثبت معتبر و
پشتیبانی تلگرام وابسته است.
